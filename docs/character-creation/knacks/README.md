# Knack Candidate Catalog

This is an oversized d66 draft for cutting and playtesting. Each Knack costs **2 Skill Tokens** unless stated otherwise. Activating a Knack without a check does not hand control to the dungeon.

Roll d66 by designating one d6 as tens and another as ones.

## Exploration Knacks

| d66 | Knack | Effect |
| ---: | --- | --- |
| 11 | Never Lost Below | Learn the direction of the nearest known exit or previously visited room. |
| 12 | Stone Listener | At a wall, floor, or door, learn the most prominent sound or movement on the other side, even if ordinarily too faint to hear. |
| 13 | Hidden Seam | Reveal one concealed entrance or compartment in the current room that could plausibly exist; if none exists, learn that with certainty. |
| 14 | Trap Whisperer | Learn the trigger and one safe method of bypassing a detected mundane trap. |
| 15 | Perfect Backtrail | Retrace a route through up to three conquered rooms for a total cost of one exploration turn, provided the route has not changed. |
| 16 | Appraiser's Eye | Ask two questions about an object: its purpose, approximate value, maker, age, danger, or whether it is cursed. Receive truthful answers. |

## Design checks before adoption

- A Knack should produce a definite effect rather than merely grant +2 or advantage to a broad category.
- A Knack should remain useful for a lone adventurer; party-focused entries need a self-use case or enough alternatives.
- Reactive Knacks can be used during a dungeon action but do not alter whose turn follows that action.
- No Knack generates Skill Tokens.
- A Knack should not duplicate a signature weapon's defining benefit.
- Oracle-facing Knacks need revision after the solo oracle is designed.
- Effects referring to morale, range, inventory, or room categories remain provisional until those procedures exist.
