# Signature Gear Candidate Catalog

This is an intentionally oversized draft for cutting and combination, not an accepted equipment list.

Roll **d66** by designating one d6 as tens and another as ones. The result determines signature gear and the adventurer's +3 attribute:

- 11–26: Strength
- 31–46: Agility
- 51–66: Mind

Every entry has a free basic identity and one candidate Skill Token technique. Unless an entry says otherwise, a successful attack deals 1 damage.

## Additional Mind candidates

These can replace or merge with entries above:

- command scepter controlling a spectral hand;
- oracle bones that attack through declared ill fortune;
- ritual mask projecting fear or borrowed identities;
- witch lantern burning spirits and revealing hidden paths;
- mirrored orb reflecting hostile magic;
- surgeon's case enabling precise anatomical attacks;
- inscribed gauntlet shaping force at Near range;
- animated quill writing commands into the air;
- saint's finger-bone calling down judgment;
- bottled imp that bargains for each effect;
- dreamcatcher weaponizing sleep and memory;
- tuning fork that cracks stone, glass, and wards.

## Cutting guidance

When reducing this catalog:

- keep equal numbers of Strength, Agility, and Mind results;
- preserve different tactical jobs rather than several cosmetic versions of the same benefit;
- retain at least one simple option and one strange option per attribute;
- avoid too many unconditional sources of advantage or 2 damage;
- check that every result functions for a lone adventurer as well as in a party;
- decide whether magical gear is common enough to occupy one-third of the table.
