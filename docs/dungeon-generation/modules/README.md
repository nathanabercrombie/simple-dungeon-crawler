# Modular Domain and Theme Cards

Room generation does not require a bespoke table for every Domain × Theme pair.

Each site uses:

- one reusable **Domain card**;
- one reusable **Theme card**;
- the universal room-template, Challenge, Opportunity, and Danger Rank procedures.

## Domain card schema

A compact Domain card contains one six-row table with these columns:

- **Function:** what this part of the site was built to do;
- **Fixture:** a physical element that makes the room specific;
- **Actor:** a person, role, creature, or trace associated with the original site;
- **Valuable:** a Domain-appropriate reward or resource;
- **Security:** a trap, restriction, lock, taboo, or defensive principle.

Roll separately in whichever column the generated Challenge or Opportunity needs. Do not roll every column for every room.

## Theme card schema

A compact Theme card contains one six-row table with:

- **Sign:** sensory evidence that the Theme is present;
- **Manifestation:** what the Theme actively does;
- **Drive:** what the altered inhabitants or site condition wants;
- **Anchor:** an object, place, event, or condition sustaining the Theme;
- **Boon:** something useful gained by understanding or engaging with it.

Again, roll only the columns needed to complete the current room.

## Assembly

1. Generate and place the room template.
2. Roll Challenge and Opportunity.
3. Roll a Domain Function to establish the room's original purpose.
4. Roll one Domain or Theme field needed by the Challenge.
5. Roll one Domain or Theme field needed by the Opportunity.
6. Combine those results with terrain and Danger Rank into one actionable situation.

The generator should usually require two or three small-table rolls after Challenge and Opportunity, not every field on both cards.

## Example

For a Haunted Tomb:

- Tomb Function: embalming chamber.
- Challenge: social obstacle.
- Haunted Drive: expose a hidden betrayal.
- Opportunity: shortcut.
- Tomb Security: funeral procession route.

Result: the embalmer's ghost blocks a concealed processional stair until the adventurers identify which corpse was secretly substituted before burial.
