# Local Web App

## Purpose

Provide optional, fast access to the game's procedural generators and, if useful later, lightweight play aids such as trackers or printable output.

## Constraints

- Runs locally.
- Lightweight to install and launch.
- Usable without a hosted service or account.
- Keeps the underlying game procedures visible and reproducible with physical dice.
- Does not become a prerequisite for playing the TTRPG.

## Status

No framework or architecture has been selected. The software scope should follow the game procedures: choose the first generator only after its tabletop version is defined.
